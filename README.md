## Important scope note
This package is intentionally limited to **Part 1: Building the Foundation - Project Initiation and Planning**.

It does **not** implement the Part 2 CSS styling or the Part 3 JavaScript/SEO functionality. The website contains a clean HTML foundation, an AI-generated hero image, clear content and working page-to-page navigation. The more advanced gold/black visual treatment and animations are planned in the proposal for later parts rather than being submitted as completed Part 2/3 work.

## 2. Where to put everything
1. Create one main folder named `AESTHETIC_SURVILLENCE_PART1_SIMPLE`.
2. Put the five `.html` files directly inside that main folder.
3. Put `hero-ai-generated.png` inside the `images` folder.
4. Keep `css` and `js` folders empty for Part 1; they are shown in the required folder structure because the assignment refers to them, but the styling and scripting work belongs to later parts.
5. Put the proposal, research notes, sitemap, wireframe and placement guide inside `docs`.

## 3. How to open the website
1. Install Visual Studio Code.
2. Open the `AESTHETIC_SURVILLENCE_PART1_SIMPLE` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension if it is installed.
4. Test Home -> About -> Services -> Enquiry -> Contact.

## New visual assets
- `assets/logo.svg` is the project logo and should stay in `assets`.
- `images/services/` contains the six AI-generated service images used on `services.html`.
- Every page loads `css/style.css` for the simple black/white/gold presentation.

### Placement rule
Keep the five HTML files in the root folder, keep the logo in `assets`, keep service pictures in `images/services`, and do not rename files unless you also update the matching HTML path.
