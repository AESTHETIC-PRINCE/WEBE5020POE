# Part 1 Placement Guide

## The simplest way to build the project

### Step 1 - Create the main folder
Create one folder called:
`AESTHETIC_SURVILLENCE_PART1_SIMPLE`

### Step 2 - Create these folders inside it
- `images`
- `css`
- `js`
- `docs`

### Step 3 - Put the HTML files in the main folder
Do **not** put the HTML files inside another folder. The main folder should directly contain:
- `index.html`
- `about.html`
- `services.html`
- `enquiry.html`
- `contact.html`

### Step 4 - Put the image in `images`
Place `hero-ai-generated.png` here:
`AESTHETIC_SURVILLENCE_PART1_SIMPLE/images/hero-ai-generated.png`

### Step 5 - Leave `css` and `js` empty
These folders are kept because the assignment's Part 1 folder structure lists them. Do not complete Part 2 or Part 3 inside this submission.

### Step 6 - Put planning documents in `docs`
The `docs` folder contains only the Part 1 planning/support files requested by the brief.

### Final folder check
```text

│
```
