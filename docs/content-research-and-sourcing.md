# Content Research and Sourcing - Part 1

## Organisation
Aesthetic Survillence is a proposed small security business created for this academic website project. The project owner is Trevor Makhubela. The business concept focuses on discreet security for private clients, businesses and events, using a mix of trained personnel, vehicles and drone-based surveillance.

## Content planned for the five pages

### Home
- Brand introduction
- Short value statement
- Hero image
- Core service summary
- Calls to explore services and make an enquiry

### About
- Organisation overview
- Mission
- Vision
- Values
- Target audience

### Services
- Drone surveillance
- VIP and executive protection
- Secure transport
- Site security
- Event security
- Security consultation

### Enquiry
- Name
- Email
- Phone
- Service selection
- Enquiry details

### Contact
- Proposed head office location
- Proposed service locations
- Contact details
- Link to enquiry page

## Asset sourcing
The hero image is an AI-generated visual prepared for this project. It is not copied from another website. The file is stored locally in the `images` folder so the website remains self-contained.

## Content originality
The organisation profile, service descriptions, mission, vision and website copy were written for this project. Any later factual client information should be replaced with approved real-world information if the lecturer/client requires it.
